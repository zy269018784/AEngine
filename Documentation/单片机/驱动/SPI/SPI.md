| 引脚   | 描述            |
|------|---------------|
| SCK  | 时钟            |
| MOSI | 主输出, 从输入      |
| MISO | 主输入, 从输出      |
| SS   | 一个从设备对应一个片选信号 |

| 特点   | 描述 |
|------|----|
| 全双工  |    |
| 同步通信 |    |
| 高速   |    |


| 时钟极性SKP/CPO | 时钟空间电平   |
|-------------|----------|
| 0           | 时钟空闲为低电平 |
| 1           | 时钟空闲为高电平 |

| 时钟相位CKE/CPHA | 时钟空间电平       |
|-------------|--------------|
| 0           | SCK的第一个跳变沿采样 |
| 1           | SCK的第二个跳变沿采样 |


|        | CPHA = 0                               | CPHA = 1                               |
|--------|----------------------------------------|----------------------------------------|
| CPOL = 0 | 第一次跳变为上升沿, 数据采样; <br> 第二次跳变为下降沿, 数据输出; | 第一次跳变为上升沿, 数据输出; <br> 第二次跳变为下降沿, 数据采样; |
| CPOL = 1 | 第一次跳变为下降沿, 数据采样; <br> 第二次跳变为下降沿, 数据输出; | 第一次跳变为下降沿, 数据输出; <br> 第二次跳变为下降沿, 数据采样; |


时钟:
有主设备产生.

片选引脚:
每个从设备对应一个片选线.

有两种模式:
主模式
从模式

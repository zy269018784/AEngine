例子:
```c
st7789_handle_t Handle = {
    .spi_init             = SPI_Init,
    .spi_deinit           = SPI_DeInit,
    .spi_write_cmd        = SPI_WriteCmd,
    .cmd_data_gpio_init   = CmdDataGpioInit,
    .cmd_data_gpio_deinit = CmdDataGpioDeInit,
    .cmd_data_gpio_write  = CmdDataGpioWrite,
    .reset_gpio_init      = ResetGpioInit,
    .reset_gpio_deinit    = ResetGpioDeInit,
    .reset_gpio_write     = ResetGpioWrite,
    .debug_print          = DebugPrint,
    .delay_ms             = DelayMs,
    .column               = 240,
    .row                  = 320,
    .format               = ST7789_FORMAT_RGB565,
};
st7789_init(&Handle);

st7789_display_on();
```

写像素流程:
    重置列地址
    重置行地址
    发送地址
    内存写命令RAMWR
    写颜色值


| 工具 | 作用 | 输入 | 输出 |
|------|------|------|------|
| `armcc` | C 编译器 | `.c` | `.o` |
| `armcpp` | C++ 编译器 | `.cpp` | `.o` |
| `armasm` | 汇编器 | `.s`（armasm 语法） | `.o` |
| `armlink` | 链接器 | `.o` / `.a` | `.axf` |
| `fromelf` | 格式转换 | `.axf` | `.hex` / `.bin` |


.o 链接成axf
armlink --cpu Cortex-M3 --ro-base 0x08000000 --rw-base 0x20000000 --entry Reset_Handler --map --list=Template.map -o Template2.axf main.o startup_stm32f10x_hd.o


armlink --cpu Cortex-M3 --ro-base 0x08000000 --rw-base 0x20000000 --entry Reset_Handler --first startup_stm32f10x_hd.o(RESET) --map --list=Template.map -o Template2.axf main.o startup_stm32f10x_hd.o

.axf变成hex
fromelf --i32 -o Template.hex Template.axf

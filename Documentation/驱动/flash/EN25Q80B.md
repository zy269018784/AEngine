| Symbol | Pin Name |
| :--- | :--- |
| CLK | Serial Clock Input |
| DI (DQ0) | Serial Data Input (Data Input Output 0) *1 |
| DO (DQ1) | Serial Data Output (Data Input Output 1) *1 |
| CS# | Chip Enable |
| WP# (DQ2) | Write Protect (Data Input Output 2) *2 |
| NC (DQ3) | Not Connect (Data Input Output 3) *2 |
| Vcc | Supply Voltage (2.7-3.6V) |
| Vss | Ground |
| NC | No Connect |

| 代码 | 描述 |
|------|------|
| 0x06 | 写使能（Write Enable），置位 WEL 位，允许后续写/擦除操作 |
| 0x04 | 写禁止（Write Disable），清除 WEL 位，禁止写/擦除操作 |
| 0x05 | 读状态寄存器（Read Status Register），获取 BUSY/WEL 等状态位 |
| 0x01 | 写状态寄存器（Write Status Register），配置保护位等 |
| 0x03 | 读数据（Read Data），从指定地址读取任意长度数据 |
| 0x0B | 快速读数据（Fast Read Data），支持更高时钟频率，带 dummy 周期 |
| 0x3B | 快速双线读（Fast Read Dual），使用 2 条数据线提高读取速度 |
| 0x02 | 页编程（Page Program），向指定页写入最多一页数据 |
| 0xD8 | 块擦除（Block Erase），擦除一个块（通常 64KB） |
| 0x20 | 扇区擦除（Sector Erase），擦除一个扇区（通常 4KB） |
| 0xC7 | 整片擦除（Chip Erase），擦除整个 Flash 芯片 |
| 0xB9 | 掉电模式（Power Down），进入低功耗状态 |
| 0xAB | 释放掉电（Release Power Down），唤醒芯片 |
| 0xAB | 读设备 ID（Device ID），唤醒并读取器件标识 |
| 0x90 | 读厂商与设备 ID（Manufacturer + Device ID） |
| 0x9F | 读 JEDEC 标准 ID（JEDEC Device ID），含厂商与容量信息 |

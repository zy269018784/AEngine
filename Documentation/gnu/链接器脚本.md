| 命令 | 描述 |
|------|------|
| SECTIONS | 定义段布局 |
| MEMORY | 定义内存区域 |
| ENTRY | 指定入口符号 |
| INCLUDE | 包含其他脚本 |
| INPUT | 指定输入文件 |
| OUTPUT | 指定输出文件 |
| GROUP | 指定一组输入库 |
| LIB | 指定库文件 |
| OUTPUT_FORMAT | 指定输出格式 |
| TARGET | 指定目标格式 |

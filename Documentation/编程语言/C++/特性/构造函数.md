| 构造函数类型 | 描述 | 是否默认有 | 如何定义 |
| :--- | :--- | :--- | :--- |
| **默认构造函数** | 无参构造，创建对象 (`MyClass obj;`) | ✅ | `MyClass() = default;` 或 `MyClass() {}` |
| **普通构造函数** | 带参构造，初始化成员 (`MyClass obj(10);`) | ❌ | `MyClass(int x) : val(x) {}` |
| **拷贝构造函数** | 用同类型对象拷贝构造 (`MyClass obj2(obj1);`) | ✅ | `MyClass(const MyClass& other) : val(other.val) {}` |
| **移动构造函数** (C++11) | 转移资源而非拷贝 (`MyClass obj2(std::move(obj1));`) | ✅ | `MyClass(MyClass&& other) noexcept : val(std::exchange(other.val, 0)) {}` |
| **转换构造函数** | 单参数构造，支持隐式类型转换 (`MyClass obj = 10;`) | ❌ | `MyClass(int x) : val(x) {}` |
| **委托构造函数** (C++11) | 一个构造函数调用另一个构造函数，减少重复代码 | ❌ | `MyClass() : MyClass(0) {}` |
| **继承构造函数** (C++11) | 使用 `using Base::Base;` 继承基类构造函数 | ❌ | `using Base::Base;` |
| **explicit 构造函数** | 禁止隐式转换，必须显式调用 (`MyClass obj(10);`) | ❌ | `explicit MyClass(int x) : val(x) {}` |
| **constexpr 构造函数** (C++11) | 编译期创建对象，用于常量表达式 | ❌ | `constexpr MyClass(int x) : val(x) {}` |
| **=default 构造函数** (C++11) | 使用编译器生成的默认版本 | ❌ | `MyClass() = default;` |
| **=delete 构造函数** (C++11) | 禁止使用特定构造函数（如禁止拷贝） | ❌ | `MyClass(const MyClass&) = delete;` |

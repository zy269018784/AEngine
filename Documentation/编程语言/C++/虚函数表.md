虚函数表是在编译时生成的，用于存储虚函数的地址。 虚函数指针是在运行时设置的，存储在每个对象的内存中，指向该对象所属类的虚函数表。
当通过基类指针调用虚函数时，程序会通过虚函数指针找到虚函数表， 再根据表找到正确的函数地址。 
这个机制是 C++ 实现多态的基础，确保了基类指针可以在运行时动态调用派生类的函数，并且避免了不必要的运行时开销。

编译时:
    虚函数表是在编译时生成的，用于存储虚函数的地址。
运行时:
    虚函数指针是在运行时设置的，存储在每个对象的内存中，指向该对象所属类的虚函数表。
